# Git в IDE vs Терминал

## 3 удобных вещи в VS Code для работы с Git:

1. **Визуальный diff** — сразу видно изменённые строки с подсветкой (зелёное/красное), без команды `git diff`.

2. **История коммитов в графическом виде** — с GitLens видно, кто и когда редактировал каждую строку (git blame визуально).

3. **Встроенный редактор merge-конфликтов** — кнопки "Accept Current/Incoming Change" экономят время.

## 1 вещь, которую удобнее делать в терминале:

**Interactive rebase (`git rebase -i`)** — в IDE нет полноценного интерфейса для squash, reword и редактирования истории. Терминал даёт полный контроль.
